PS034 : Multi-Restaurant Food Ordering & Delivery Orchestration Engine

The company CraveDash Mobility Services requires a high-throughput food ordering and fulfilment system to connect restaurant partners, hungry consumers, and delivery fleets. CraveDash needs to allow users to explore dynamic digital menus, place multi-item orders, and complete digital payment transactions, while allowing restaurants to update item availability in real time. The company mandates microservices that isolate restaurant menu management, order workflow orchestration, payment processing, and delivery fulfillment. This system must support secure access, scalable service discovery, and resilient communication between the order, restaurant, and payment domain services.

Sample Microservices

  • Restaurant Service
  • Order Service
  • Payment Service (API Gateway, Auth, Eureka)

Tasks to be Done

  • Secure APIs using JWT Authentication
  • Use API Gateway for centralized access
  • Enable Eureka Discovery for services
  • Apply Load Balancing for order requests
  • Implement Inter-service Communication (Order <-> Restaurant <-> Payment)
  • Develop APIs for menu, order, payment, and tracking
  • Write Unit + Integration Tests
  • Deploy services
Note: The team leader can apply to change the review.
